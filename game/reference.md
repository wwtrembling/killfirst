## 2. 1인 게임 개발 안티패턴

| 안티패턴 | 설명 | 대응 |
|----------|------|------|
| 스코프 크리프 | "이것도 추가하자" 반복 | 코어 기능 3-5개 고정, 나머지는 v2 |
| 아트 함정 | "좀 더 예쁘게" 루프 | 이모지/텍스트/기하도형으로 시작, 검증 후 아트 투자 |
| 엔진 학습 | Unity/Godot 배우느라 3개월 | 기존 웹 스택(HTML/CSS/JS + Workers)으로 시작 |
| 완벽주의 | "출시할 수준이 아니다" | 48시간 플레이테스트 → 피드백 기반 개선 |
| 양면 시장 | "유저가 모여야 재밌다" | 싱글플레이 또는 비동기 멀티 먼저 |
| 콘텐츠 트레드밀 | 매주 새 콘텐츠 수동 제작 | AI 생성 또는 절차적 생성으로 자동화 |
| 밸런싱 지옥 | PvP 메타 끝없는 패치 | PvE 또는 협동 먼저, PvP는 검증 후 |

## 3. 추천 플랫폼 분석

### Telegram Mini App (1순위)
- **장점**: 950M+ MAU, Mini App = 웹앱(기존 스택 활용), 빌트인 배포(채팅 공유), 빌트인 인증, Telegram Stars 결제
- **주의**: 유저 데모 CIS/중동/동남아 편중, 플랫폼 정책 변경 리스크
- **기술**: Telegram Bot API + WebApp API + Cloudflare Workers/Pages/D1

### 웹 브라우저 (2순위, 서브)
- **장점**: Cloudflare Pages 무료, 크로스플랫폼, SEO/소셜 공유, itch.io/CrazyGames 등록 가능
- **주의**: 모바일 웹 UX 한계, 푸시 알림 없음
- **기술**: HTML5 Canvas 또는 DOM, CSS, Vanilla JS 또는 경량 프레임워크

### 제외한 플랫폼
- **Steam**: 게임 엔진 학습 필수, 연 15,000+ 출시, 디스커버리 문제
- **모바일 앱**: 30% 수수료, 앱 심사, ASO, CAC $2-5+
- **Roblox**: Lua 학습, 75% 수수료, 기존 스택 활용 불가

## 6. 게임 특화 kill 기준 요약

1. 30초 재미 — 코어 루프 한 문장, 튜토리얼 없이 이해
2. 공유 트리거 — 공유할 포맷 존재 (점수/결과/텍스트)
3. 재방문 트리거 — 내일 다시 올 이유 (일일 챌린지/AI 콘텐츠)
4. 1인 아트 — 커스텀 아트 없이 가능
5. 기술 스코프 — 주말 프로토 가능
6. 수익화 — "누가 무엇에 얼마를" 한 문장
