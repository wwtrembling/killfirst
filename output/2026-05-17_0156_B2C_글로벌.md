## 회고: 왜 0건인가

### 구조적 사유
1. **B2C $3~$30/월 가격대는 무료 OS 기능과 직접 충돌**. iOS 18 Apple Intelligence(요리/요약), Microsoft Recall(브라우저 brain), Strava 본체(연 누적), Foundry VTT(그리드), Reddit Premium(새 댓글)이 후보 9개 중 5개를 무료 흡수.
2. **카테고리 리더 + VC 자본 포화**. Cold Turkey, Rocket Money, Readwise Reader, Rewind, Archivist 등이 동일 영역 선점.
3. **사용자 결제 의향 = 0**. 브라우저 익스텐션 70k 사용자에 매출 거의 없음(Indie Hackers 사례) — B2C 무료 기대치가 강함.
4. **API 정책 리스크**. Strava 2024.11 약관, Reddit API 2023 대학살, Gmail CASA 감사 비용 → 1인 개발자 데이터 의존 불가.

### 일반론 (whereirank.net 교훈 강화)
- 메인이 "차별점 1개" 주장 시 web_search로 실제 검증 필수. 1차 반박에서 메인이 든 차별점 3건이 사실관계 오류였음을 red-team 2차에서 확인.
- "검색 결과 경쟁자 없음 = 시장 있음" 추론은 위험. 시장 부재 가능성도 동등.
- $3~$10/월 B2C 가격대는 무료 대안 풍부 → 가격 자체가 첫 $100 매출의 함정.

### 다음 시도 권장
- **B2B 또는 B2C 프리미엄($30+/월)** 가격대로 이동 → 무료 대안과 거리 두기
- 데이터 독점 우위가 있는 카테고리만 → 1인 개발자가 모을 수 있는 unique data
- 또는 1차 26건 + 2차 26건 중 미사용 페인 포인트(예: 3D프린팅 입문 노하우 통합, 양봉 사진 점검 로그 등 hyper-niche)로 4번째 시도 — 다만 본 시스템에서는 재시도 회수 소진
