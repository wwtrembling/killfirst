### 2. swak.ph (2026-05-11 STOP)
"PBA의 Basketball Reference" — 필리핀 농구 고급 분석 플랫폼. Cloudflare Workers + Hono + Astro + D1. 6개 리그 수집기, 8개 크론, 29개 웹 페이지까지 구현 후 시장조사에서 PMF 부재 확인.

**실패 원인:**
1. **데이터 미실증** — 6개 리그 수집기 중 PBA 1개만 작동. NBA API는 v4 없음(404)+인증 미구현, KBL은 Flutter SPA로 파싱 불가, EuroLeague는 봇 차단. whereirank과 동일 패턴 반복.
2. **경쟁자 간과** — RealGM이 PBA 고급 통계(PER, ORtg, DRtg)를 이미 무료 제공 중. "경쟁자 없음" 전제가 틀렸음.
3. **시장 수요 부재** — 5개 플랫폼(Reddit/YouTube/InterBasket/Twitter/Facebook) 딥 조사 결과: r/PBA 57K 커뮤니티에서 도구 요청 포스트 0건. 유일한 분석 포스트는 downvote(ratio 0.41). PBA 전용 분석 계정 전 세계 0개. PBA Memes(141만) >>> 분석 수요. **팬은 농구를 "느낌"으로 소비하며 고급 통계를 원하지 않는다.**
4. **수익 불가** — 필리핀 Tier 3 AdSense RPM $1~3. MAU 8K로 $36~60/월이 한계. 목표($300~500)의 1/5.

**whereirank 대비 개선된 점:**
- 이번에는 시장조사를 실시하고 조기 중단함 (코드 완성 전)
- kill criteria를 사전에 설정해둠

**교훈:**

- "경쟁자가 없다"는 건 "수요가 없다"는 신호일 수 있다
- "누가 왜 돈을 내는가"를 한 문장으로 답할 수 없으면 시작하지 마라
